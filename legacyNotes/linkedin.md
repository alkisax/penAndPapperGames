### ✏️ Pen and Paper Games — React Native + .NET SignalR

A collection of classic pen-and-paper games built with React Native. This project was mainly created to practice interactive SVG boards and real-time multiplayer using a reusable .NET SignalR backend.

Players can play locally, against a simple AI, or online through shared rooms with built-in chat.

Inspired by the **Tabletop Family** YouTube channel.

---

Γεια 👋
Σας παρουσιάζω το Pen and Paper Games, ένα προσωπικό portfolio project που ολοκλήρωσα με React Native και .NET.
Η αρχική ιδέα ήταν αρκετά απλή: να συγκεντρώσω σε μία εφαρμογή κλασικά παιχνίδια που μπορούν να παιχτούν μόνο με χαρτί και μολύβι.
Για εμένα όμως ο πραγματικός στόχος ήταν η εξάσκηση σε μερικά θέματα που ήθελα να γνωρίσω καλύτερα:
- React Native & Expo
- interactive SVG boards με react-native-svg
- .NET SignalR και realtime multiplayer
- reusable game architecture
- Google Play & AdMob deployment
Η εφαρμογή υποστηρίζει:
τοπικό παιχνίδι στην ίδια συσκευή, απλό AI στα παιχνίδια, online multiplayer μέσω SignalR rooms, ενσωματωμένο chat μεταξύ των παικτών

Ένα μεγάλο μέρος της υλοποίησης επικεντρώθηκε στη δημιουργία επαναχρησιμοποιήσιμων SVG boards και στη λογική που επιτρέπει στο ίδιο backend να εξυπηρετεί διαφορετικά παιχνίδια χωρίς να γνωρίζει τους κανόνες τους.

Η έμπνευση για πολλά από τα παιχνίδια προήλθε από το YouTube κανάλι Tabletop Family.

Το project είναι διαθέσιμο στο Google Play store. 🎉
