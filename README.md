# Pen and Paper Games

Pen and Paper Games is a React Native portfolio project inspired by classic
pen-and-paper strategy games. It brings a collection of simple games to mobile
and web, with support for local play, selected AI opponents, and online rooms.

The project was mainly created to practise:

- React Native
- Interactive SVG boards
- Reusable game architecture
- Realtime multiplayer with .NET SignalR

## Features

Players can:

- Play locally with two players on one device
- Play against a simple AI opponent where available
- Play online using a shared room code
- Use the built-in chat while connected
- Read the rules and instructions for every game inside the app
- Switch between light and dark themes
- Play on Android and the web

## Games

| Game | Description |
| --- | --- |
| Black Hole | Place numbers in a pyramid and try to finish with the lowest score around the final empty circle. |
| Pferdäpfel | Move chess-like knights across a board while blocking cells and trying to capture or trap the opponent. |
| Paper Airfight | Launch paper planes by choosing direction and power, then reach the goal or hit the opponent. |
| Dandelions | Place dandelions and seeds while changing wind directions to influence the board. |
| Hex | Place hexagonal pieces and try to connect your two opposite sides of the board. |
| Hedron | Claim regions on a geometric board and score them through strategic ownership. |
| Dots and Boxes | Draw edges, complete boxes, and collect more boxes than the other player. |
| Collector | Place pieces and remove neighboring spaces while building the largest connected group. |
| Nab | Move through valid paths across a board and use circles before the opponent can. |
| Imparium | Place and cover pieces while competing for control of regions on the board. |
| Snake Fight | Extend paths across a dot grid while competing for space and avoiding invalid moves. |

There is also a separate Slingshot prototype in the source project that explores
interactive aiming with an SVG control.
